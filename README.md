### Java-to-jlox

Working through Bro Code's Java tutorial (~12hr) as prep for building jlox, the tree-walking interpreter from Crafting Interpreters, which will later be followed by Clox (bytecode VM, in C).

This isn't a "learn Java for its own sake" repo in isolation — it's step zero of a bigger compiler-building path, though I'm going broad enough here (not just OOP basics) to also come out with real Java familiarity.

Why this repo exists:
- Track progress through the tutorial day-by-day
- 2Keep small exercises/snippets from each section instead of losing them
- Build the OOP + collections + exceptions foundation jlox needs
